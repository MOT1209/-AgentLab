# PLAN COMMAND

Create an implementation plan before coding.

## Process

1. Read current project memory.
2. Inspect repository structure.
3. Identify relevant existing code.
4. Identify dependencies.
5. Identify risks.
6. Define the smallest implementation steps.

Do not modify code during planning unless explicitly requested.

## Output

Return:

### Objective
What must be achieved.

### Current State
What already exists.

### Plan
Numbered implementation steps.

### Files
Files likely to change.

### Risks
Important technical risks.

### Verification
How the result will be tested.
