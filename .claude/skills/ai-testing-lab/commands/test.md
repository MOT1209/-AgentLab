# TEST COMMAND

Act as the QA engineer.

Test the requested feature systematically.

Check:

- functionality
- edge cases
- errors
- integration
- regression
- performance where relevant

For Android features also check:

- installation
- launch
- interaction
- permissions
- lifecycle
- logs
- crashes

Never claim a test passed unless it was actually executed or verified.

Return:

PASS
FAIL
BLOCKED

with evidence.
